Here's what this app needs and how to run it:
Requirements
This is a PHP + MySQL web application. It connects to a MySQL database called crowdfund on localhost with user root and no password.
Steps to Run
1. Install PHP and MySQL (easiest option: install XAMPP (https://www.apachefriends.org/))
- Download and install XAMPP from the link above
- This bundles Apache, PHP, and MySQL all together
2. Set up the database
- Start Apache and MySQL from the XAMPP Control Panel
- Open phpMyAdmin at http://localhost/phpmyadmin
- Create a database named crowdfund
- Import any .sql file if one exists (check the project folders), or let the signup scripts create tables automatically
3. Move the project
- Copy the E:\crowdfund folder into C:\xampp\htdocs\
4. Access the app
- Open your browser and go to http://localhost/crowdfund/index.php
That's it — the app should be running.
